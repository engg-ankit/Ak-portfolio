# Ankit Kumar - Premium Portfolio Website

A modern, premium portfolio website for Ankit Kumar featuring AI-powered design elements, glassmorphism effects, smooth animations, and a professional dark theme.

## ✨ Features

- **Modern Dark Theme** - Sleek dark design with accent gradients
- **Glassmorphism Effects** - Beautiful frosted glass card designs
- **Animated Backgrounds** - Particle effects and gradient animations
- **Smooth Animations** - Typing effects, skill bars, and scroll animations
- **Responsive Design** - Fully responsive across all devices
- **Interactive Elements** - Hover effects, smooth scrolling, and dynamic navigation
- **SEO Optimized** - Meta tags and semantic HTML structure
- **Fast Loading** - Optimized for performance

## 🎨 Design Elements

## 🚀 Getting Started

1. Clone or download this repository
2. Place your profile image at `assets/images/profile.jpg`
3. Open `index.html` in a web browser

## 🔧 Customization

To customize the portfolio for your own use:

1. Update personal information in `index.html`
2. Modify colors in CSS variables in `style.css`
3. Update projects and skills sections
4. Replace profile image in `assets/images/`
5. Update contact information and social links
